# Experimental Data

This folder contains supporting experimental data used in the CP302 Study of Active Dispersion project.

## Included files

- `Blob trajectory.csv`: Manual blob trajectory measurements.
- `EXP1 Trim.mdf`: MTrackJ tracking data.
- `frame_000362_t12.033.png`: Representative experimental image frame.

## Raw image sequence

The complete raw dataset is retained separately and is not included in this GitHub repository because of its size.

- 1,266 TIFF images.
- One background image and 1,265 numbered experimental frames.
- Approximate total raw-data folder size: 7.39 GB.
- Original location: `01_Experimental_Data/raw_data`.

The original TIFF files should be retained without modification. Their availability and transfer should be arranged separately if required.

## Data interpretation

The CSV and MDF files are supporting tracking data. Their correspondence with the complete experimental image sequence, calibration, and time intervals must be independently established before using them for quantitative validation.
